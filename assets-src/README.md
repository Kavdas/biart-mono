# Исходные декоративные ассеты

Копии до пережатия: росчерки-submark, леттеринг направлений, иллюстрации и персонажи.
В теме лежат версии под реальный размер отрисовки (росчерк показывается 620px при
непрозрачности 10%, леттеринг — 200px, иллюстрации — около 300px), поэтому исходные
1400px там были лишним весом.

Эти файлы в сборку сайта не попадают — нужны, чтобы пережать заново с другими
параметрами, если поменяется вёрстка.
