# CRM заявок в Google Таблице

Сайт (форма «Заявка на аренду», «Запись», «Возникли вопросы») при отправке:
1. открывает WhatsApp менеджера с готовым текстом, который начинается с **«Заявка с сайта BIART · …»**;
2. если подключена таблица — тихо дописывает строку в Google Таблицу (колонки: дата, источник, имя, телефон,
   событие, желаемая дата, гостей, комментарий, **статус**, ответственный, дата звонка, заметки).
   Ошибка таблицы не мешает WhatsApp.

## Подключение (один раз)

1. Создайте Google Таблицу (или импортируйте `crm/template.csv`), назовите «BIART CRM».
2. Расширения → Apps Script → вставьте содержимое `crm/apps-script.gs` → сохранить.
3. Выполните `prepare` (кнопка «Выполнить», разрешите доступ) — лист «Заявки» получит шапку, фильтры, список статусов
   и цветную подсветку.
4. Развернуть → Новое развёртывание → тип «Веб-приложение»: выполнять от своего имени, доступ — «Все».
   Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
5. В `wp-config.php` (или в `.wp-env.json` → `config`) добавьте
   `define( 'BIART_CRM_URL', 'https://script.google.com/macros/s/…/exec' );` и перезалейте страницы.
6. Для статичного демо: `BIART_CRM_URL` задаётся при генерации страниц (слепок возьмёт адрес из формы);
   политика безопасности слепка разрешит `script.google.com` только если адрес задан.

## Как работать менеджеру
Фильтр по «Статус = Новая» → позвонить (телефон лежит текстом — на телефоне нажатием набирается) → поставить статус
(«Перезвонить», «В работе», «Договорились», «Отказ»), указать ответственного и дату звонка. Цвет строки меняется сам.

## Персональные данные
В таблице лежат имя и телефон клиентов: доступ — только сотрудникам, у кого он нужен; таблицу не публикуйте
по ссылке. Согласие на обработку берётся в форме (чекбокс). В тексте политики конфиденциальности стоит упомянуть
хранение заявок в Google Таблице — текст политики менять должен юрист школы.
