# Исходные шрифты

Полные версии фирменных шрифтов до сабсеттинга. В теме (`theme/assets/fonts/`)
лежат урезанные копии — только латиница, кириллица (включая казахские буквы),
пунктуация, стрелки и знак тенге. Это втрое легче и заметно ускоряет первую загрузку.

Пересобрать урезанные версии: `python tools/subset-fonts.py`
(нужен `fonttools` с `brotli`: `pip install fonttools brotli`).

Эти файлы в сборку сайта не попадают — они здесь, чтобы можно было
пересобрать сабсет, если понадобятся новые символы.
