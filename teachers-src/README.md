# Преподаватели направлений

Здесь лежат данные и фото преподавателей, которые показываются в окне арт-куратора
(клик по карточке куратора в «Команде» → внизу окна «Преподаватели»).

**Как добавить преподавателя**

1. Положите фото сюда (`teachers-src/`): портрет 3:4, от 800 px по ширине, JPG/PNG.
2. В `teachers.json` в нужном кураторе и направлении добавьте запись:
   `{"name": "Имя Фамилия", "role": "Фортепиано", "photo": "ivanova.jpg", "regalia": ["Лауреат …", "Стажировка …"]}`
   (казахский вариант — `name_kz`, `role_kz`, `regalia_kz`, необязательно).
3. Выполните `python3 tools/build-teachers.py` — скрипт соберёт фото в WebP нужных размеров и обновит
   `theme/content/home.html` и `home-kz.html`. Затем `npm run seed`.

Запись с `"draft": true` — заглушка: на странице она видна как карточка-макет. Перед публикацией уберите
`draft` у всех записей — `tools/export-static.py` предупредит, если заглушки остались.
